    Component Details¶

    This document provides detailed information about each component in the RAG system.

    Service Layer Components¶

    RAG Pipeline¶

    File: backend/app/services/rag_pipeline.py

    Responsibility: Orchestrates the entire RAG (Retrieval-Augmented Generation) process.

    Architecture¶

    graph LR A[Question] --> B[RAG Pipeline] B --> C[Vector DB Service] B --> D[LLM Service] B --> E[Prompt Manager] C --> F[Context] E --> G[Prompt Template] F --> H[Formatted Prompt] G --> H D --> I[Answer] H --> D F --> J[Sources] I --> K[Response] J --> K style B fill:#f3e5f5 style C fill:#e8f5e9 style D fill:#fce4ec style E fill:#fff3e0

    Key Methods¶

    class RAGPipeline:

    Flow Diagram¶

    sequenceDiagram participant Client participant RAG as RAG Pipeline participant VDB as Vector DB participant PM as Prompt Manager participant LLM as LLM Service Client->>RAG: answer_question(q) RAG->>VDB: search_documents(q, top_k=5) VDB->>VDB: Embed query VDB->>VDB: Cosine similarity VDB-->>RAG: chunks[5] alt Has Context RAG->>PM: build_prompt(chunks, q) PM-->>RAG: formatted_prompt RAG->>LLM: generate(prompt) LLM-->>RAG: answer RAG-->>Client: {answer, sources} else No Context RAG->>PM: get_no_context_message() PM-->>RAG: fallback_message RAG-->>Client: {answer: fallback, sources: []} end

    Vector DB Service¶

    File: backend/app/services/vector_db.py

    Responsibility: Document indexing, embedding, and semantic search.

    Architecture¶

    graph TB A[Documents] --> B[Text Splitter] B --> C[Header Splitter] B --> D[Recursive Splitter] C --> E[Chunks] D --> E E --> F[Sentence Transformer] F --> G[Embeddings 384D] G --> H[ChromaDB] I[Query] --> J[Embed Query] J --> K[Search ChromaDB] H --> K K --> L[Top K Results] style B fill:#e8f5e9 style F fill:#fff3e0 style H fill:#e0f2f1

    Chunking Strategy¶

    # 1. Header-based splitting (preserves structure)
MarkdownHeaderTextSplitter(
    headers_to_split_on=[
        ("#", "Header 1"),      # Main sections
        ("##", "Header 2"),     # Subsections
        ("###", "Header 3"),    # Details
    ]
)

# 2. Recursive splitting (handles overflow)
RecursiveCharacterTextSplitter(
    chunk_size=800,           # Target size
    chunk_overlap=200,        # Context preservation
    separators=["\n\n", "\n", ". ", " ", ""]
)

    Example:

    Input: 

    # Benefits

## Health Insurance
We offer comprehensive health insurance...

### Dental Coverage
Dental is included...

    Output Chunks: 

    [
    {
        "text": "Health Insurance\nWe offer comprehensive...",
        "metadata": {
            "Header 1": "Benefits",
            "Header 2": "Health Insurance"
        }
    },
    {
        "text": "Dental Coverage\nDental is included...",
        "metadata": {
            "Header 1": "Benefits",
            "Header 2": "Health Insurance",
            "Header 3": "Dental Coverage"
        }
    }
]

    Usage¶

    pm = PromptManager()

# Build complete prompt
prompt = pm.build_prompt(
    question="What is vacation policy?",
    context_chunks=[chunk1, chunk2]
)

# Format context
formatted = pm.format_context(chunks)

# Get fallback message
fallback = pm.get_no_context_message("vacation")

    Database Connection¶

    File: backend/app/database/connection.py

    Pattern: Singleton

    class ChromaDBConnection:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialize()
        return cls._instance

    def get_collection(self, name: str):
        """Get or create collection"""

    def reset_collection(self, name: str):
        """Delete and recreate collection"""

    Why Singleton? - ChromaDB client should be shared - Avoid multiple connections - Connection pooling - Resource efficiency

    Batch Processing¶

    # Index multiple documents efficiently
def index_directory(self, directory_path: str):
    files = list(Path(directory_path).glob("*.md"))

    # Process in batches
    batch_size = 10
    for i in range(0, len(files), batch_size):
        batch = files[i:i + batch_size]
        self._index_batch(batch)
